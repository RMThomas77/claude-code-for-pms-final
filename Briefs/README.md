# Briefs

Put every brief in this folder, one file per brief (Markdown preferred).

A scheduled run of the `review-checklist` skill looks here every Monday morning. It reviews any brief added or changed since the previous run and reports what it finds.

To get a brief reviewed, save it here, with a short descriptive file name (for example `vesper-quiet-responder-fix.md`).

Keep this README. The scheduled run ignores it.
